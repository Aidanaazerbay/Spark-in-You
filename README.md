### ✨ Spark In You
**Spark In You** is a web platform designed to bridge the gap between communities affected by inequality and the resources, funding, and support networks they need to build resilience and drive systemic change.
## Key Features & Modules
### 1. Core Support Sections
* **Legal Help (`LawHelp`):** Access to legal resources, updates on legislation (e.g., domestic violence regulations), and expert insights.
* **Financial Help (`Financial Help`):** Employment opportunities, training programs, financial education, and support tracking (such as assistance for families affected by natural disasters).
* **Social Help (`SocialHelp`):** Community building, psychological support resources, and blog integrations.
### 2. User Accounts & Community
* **Personal Dashboard:** User registration, profile management, and personalized assistance.
* **Blogging Platform:** A Reddit-style blogging system allowing users to share insights and participate in community discussions.
## Tech Stack & Architecture
* **Backend:** C#, ASP.NET Core MVC (Controllers, Models, Views architecture)
* **Frontend:** HTML5, CSS3, JavaScript
* **Tools:** Visual Studio, Git / GitHub
